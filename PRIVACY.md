# Privacy policy: PE LP Accounting plugin

**Effective date:** 24 November 2026
**Publisher:** patwalshailender-jpg · Contact: patwal.shailender@gmail.com

## Summary

The PE LP Accounting plugin consists only of instructions and reference material for Claude (Markdown, JSON and an icon). It has no server, no database, no MCP servers, no network calls and no analytics. The publisher receives no data from users of the plugin.

## What data the plugin handles

| Data | How it is handled |
|---|---|
| Documents and text the user provides in a Claude conversation (for example LPAs, capital call and distribution notices, capital account statements, NAV reports, fund financial statements) | Read by Claude within the user's conversation to produce the requested output. These documents may contain personal data such as names, email addresses and signatures of fund contacts, or KYC / FATCA / CRS information. |
| Outputs (journals, reconciliations, reports, memos) | Produced in the user's conversation. If the user asks Claude to file documents, they are saved only to storage the user has connected and controls. |

## What the plugin does not do

- It does not store, retain or transmit any data to the publisher or to any third party.
- It does not send data to any service other than those the user has connected to Claude themselves.
- It does not read or use credentials, API keys or passwords.
- It does not run code outside Claude's own tools; calculations are performed by Claude's code-execution or analysis tool at the user's request.

## Retention

The plugin retains no data. Conversation data is handled under the user's agreement with Anthropic, and any filed documents under the user's own storage provider's terms.

## Users

The plugin is intended for finance professionals and is not intended for users under 18.
